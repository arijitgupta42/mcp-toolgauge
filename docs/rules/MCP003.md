# MCP003 -- name subject missing from description

**Severity:** warning &nbsp;&nbsp; **Rule name:** `name-subject-missing-from-description`

A subject named in the tool name never appears in its description.

## Why it matters

Selection is retrieval, and retrieval matches the user's phrasing against the whole
tool definition, not just the name. A tool called `search_users` whose description
says only "searches the database and returns matching records" mentions users
exactly once in its entire definition. Its sibling `search_orgs` has the same
description, so a request about people has nothing to prefer one over the other.

This is usually a copy-paste artefact: one description written once and pasted onto
every tool in the family, with only the name changed.

## Triggers when

A subject word from the name does not appear in the description. Verbs and generic
nouns are stripped from the name first, so `search_users` only has to justify
"users" -- a description reading "Find people... the user is looking for" passes.
Matching is prefix-based for words of four characters or more, so "organization"
matches "organizations".

## Before

```python
@mcp.tool()
def search_users(query: str) -> list[User]:
    """Searches the database and returns matching records for the query."""
```

## After

```python
@mcp.tool()
def search_users(query: str) -> list[User]:
    """Find individual people in the staff directory by name, email, or
    employee ID. Returns one entry per matching person."""
```
