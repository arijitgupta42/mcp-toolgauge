# MCP022 -- free string with enum candidates

**Severity:** warning &nbsp;&nbsp; **Rule name:** `free-string-with-enum-candidates`

A free-form string parameter looks like it has a fixed set of valid values.

## Why it matters

`status: str` is an invitation to hallucinate. The model has to produce something,
so it produces a plausible-looking value -- "in progress" when your API wants
"pending" -- and the call fails at validation. To the user that reads as the tool
being broken, not as a schema that never said what it accepted.

An `enum` removes the guess entirely. The model can only emit a value that works,
and it no longer has to infer your vocabulary from the description.

## Triggers when

A string parameter with no `enum`, `const`, `pattern`, or `format`, where either the
name is one that almost always denotes a closed set (`status`, `type`, `priority`,
`mode`, `format`, `region`, `role`, and similar) or the description enumerates the
values in prose ("one of", "either", "valid values").

## Before

```python
priority: str = "normal"
status: str
```

## After

```python
priority: Literal["low", "normal", "high", "urgent"] = "normal"
status: Literal["open", "pending", "solved", "closed"]
```
