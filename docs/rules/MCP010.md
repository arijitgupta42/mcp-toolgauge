# MCP010 -- missing description

**Severity:** error &nbsp;&nbsp; **Rule name:** `missing-description`

The tool has no description at all.

## Why it matters

The most expensive defect a tool can have, and the cheapest to fix. With no
description a model has only the name and the parameter list, and it will reliably
prefer any sibling that explains itself -- including a worse-suited one.

In practice an undescribed tool is close to invisible. It is not that it gets picked
less often; it is that it stops being a candidate.

## Triggers when

The tool's `description` is absent, empty, or whitespace only. All three are the
same defect and are reported identically: mcp-doctor normalises a blank description
to absent when it reads one off the wire.

## Before

```python
@mcp.tool(description="")
def run(payload: dict) -> dict:
    return _process(payload)
```

## After

```python
@mcp.tool()
def run_export_job(payload: ExportRequest) -> ExportResult:
    """Start an export job and return its ID and estimated completion time.

    Use this for exports over 10,000 rows. Smaller exports are faster through
    `export_directory_csv`, which returns the data directly."""
```
