# MCP011 -- description too short

**Severity:** warning &nbsp;&nbsp; **Rule name:** `description-too-short`

The description is a fragment rather than a sentence.

## Why it matters

A fragment gives retrieval almost nothing to match a user's phrasing against. Real
requests are sentences -- "find me everyone on the platform team" -- and they match
descriptions that are also sentences. "Search." matches nothing in particular.

A good description does three jobs: says what the tool does, says when to reach for
it rather than a sibling, and says what comes back. None of those fit in three words.

## Triggers when

The description is fewer than six words, or contains no sentence-ending punctuation
at all. Six words is roughly the shortest string that can name a subject and say
something about it.

## Before

```python
@mcp.tool()
def search(q: str) -> list:
    """Search."""
```

## After

```python
@mcp.tool()
def search_users(query: str) -> list[User]:
    """Find people in the staff directory by name, email, or employee ID.
    Returns one entry per match with their title and organization."""
```
