# MCP015 -- placeholder text

**Severity:** error &nbsp;&nbsp; **Rule name:** `placeholder-text`

A description still contains placeholder text.

## Why it matters

Placeholder text is not neutral. The model reads it, and a tool whose description
says `TODO: document this properly` reads as unfinished -- which makes it both hard
to select correctly and, to a cautious client, unsafe to call.

It is also the most visible sign of an unreviewed surface to anyone deciding whether
to depend on your server.

## Triggers when

The tool's description, or any parameter's description, contains `TODO`, `FIXME`,
`TBD`, `WIP`, `HACK`, `XXX`, `PLACEHOLDER`, `CHANGEME`, `lorem ipsum`, "coming
soon", "describe this", or an angle-bracketed insert marker.

## Before

```python
@mcp.tool()
def do_stuff(action: str, target: str) -> dict:
    """TODO: document this properly."""
```

## After

```python
@mcp.tool()
def apply_bulk_action(action: BulkAction, target_org_id: str) -> BulkResult:
    """Apply one bulk action to every ticket in an organization, and return a
    per-ticket outcome. See `action` for the operations available."""
```
