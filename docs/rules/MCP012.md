# MCP012 -- description restates the name

**Severity:** warning &nbsp;&nbsp; **Rule name:** `description-restates-name`

The description only repeats the words already in the name.

## Why it matters

`search` described as "Search." has a description in the protocol sense and none in
any useful sense. Repeating the name adds no signal; it doubles the weight of words
already present, which makes a weak name weakly stronger and teaches the model
nothing new.

Every token in a tool definition is paid for out of the context window on every
single request. A description that restates the name is the one kind of text that
costs tokens and returns nothing.

## Triggers when

Every meaningful word in the description matches a word in the tool's name, after
stopwords are removed and both sides are singularised.

## Before

```python
@mcp.tool()
def get_data(id: str) -> dict:
    """Get data."""
```

## After

```python
@mcp.tool()
def get_ticket(ticket_id: str) -> Ticket:
    """Fetch one ticket by ID, including its status, assignee, and SLA
    deadline. For the conversation on it, use `list_ticket_comments`."""
```
