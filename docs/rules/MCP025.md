# MCP025 -- no example values

**Severity:** info &nbsp;&nbsp; **Rule name:** `no-example-values`

Nothing in the tool's schema shows an example value.

## Why it matters

A model can guess what a search query looks like. It cannot guess what your IDs look
like. One concrete value in the least obvious parameter's description does more for
call success than any amount of prose about what the parameter means.

This matters most for identifiers and formatted strings, and least for free text --
which is why the fix is usually one short phrase in one description, not an example
on every field.

## Triggers when

A tool with at least one parameter where no parameter subschema carries `examples`
or `example`, and no description in the tool contains "e.g.", "for example", "for
instance", or "such as".

`default` deliberately does not count. A default is what happens when nobody says
anything; it is not a worked example of what a good value looks like.

## Before

```python
user_id: Annotated[str, Field(
    description="The user's stable identifier.",
    pattern=r"^usr_[a-z0-9]+$",
)]
```

## After

```python
user_id: Annotated[str, Field(
    description=(
        "The user's stable identifier, e.g. 'usr_1a2b'. Get one from"
        " `search_users`."
    ),
    pattern=r"^usr_[a-z0-9]+$",
)]
```
