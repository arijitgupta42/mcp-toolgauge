# MCP021 -- parameter description restates its name

**Severity:** info &nbsp;&nbsp; **Rule name:** `parameter-description-restates-name`

A parameter's description only repeats its name.

## Why it matters

"The limit" as the description of `limit` costs tokens on every request and teaches
nothing. The model already has the name.

What it actually needs is whatever the name cannot carry: the units, the accepted
range, where the value comes from, and what happens when it is omitted.

## Triggers when

Every meaningful word in the parameter's description matches a word in the parameter
name, after stopwords are removed and both sides are singularised.

## Before

```python
limit: Annotated[int, Field(description="The limit.")] = 20
status: Annotated[str, Field(description="The status.")]
```

## After

```python
limit: Annotated[int, Field(
    ge=1, le=100, default=20,
    description="Maximum number of people to return. Caps at 100.",
)] = 20
status: Annotated[TicketStatus, Field(
    description="The status to move the ticket to. Closed tickets can be reopened;
                 archived ones cannot.",
)]
```
