# MCP004 -- mixed naming conventions

**Severity:** warning &nbsp;&nbsp; **Rule name:** `mixed-naming-conventions`

The server mixes naming conventions across its tools.

## Why it matters

Every tool name a model reads is a sample of how this server names things. When the
samples disagree, the model carries an extra axis of variation that means nothing --
and so does every human reading the list.

It is also the cheapest possible signal of neglect. A tool list where nine names are
snake_case and one is camelCase reads as a surface that grew by accretion, which is
exactly what a reviewer deciding whether to depend on your server is looking for.

## Triggers when

More than one convention is in use across the server's tool names. Single lowercase
words are excluded, because `search` conforms to snake_case and camelCase alike and
it would be wrong to call that an inconsistency. Reported once, at server level.

## Before

```python
search_users
search_orgs
doStuff          # the odd one out
delete_all_tickets
```

## After

```python
search_users
search_orgs
do_stuff
delete_all_tickets
```
