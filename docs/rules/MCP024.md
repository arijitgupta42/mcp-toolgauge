# MCP024 -- untyped parameter

**Severity:** warning &nbsp;&nbsp; **Rule name:** `untyped-parameter`

A parameter has no declared type, or is an object with no declared shape.

## Why it matters

An opaque bag is the one parameter shape a model cannot fill in correctly by reading
the schema, because the schema says nothing. It falls back to guessing from the
description, if there is one, and to whatever it has seen in training otherwise.

A free-form `dict` parameter usually exists because the API grew and nobody wanted to
break the signature. Naming the two or three fields it actually carries is almost
always possible and always better.

## Triggers when

A parameter whose subschema declares no `type`, `enum`, `const`, `$ref`,
`properties`, or `items` in any branch; or one where every non-null branch is
`type: object` with no declared `properties`.

## Before

```python
def do_stuff(action: str, target: str, params: Any = None) -> Any: ...
```

## After

```python
class BulkActionOptions(BaseModel):
    dry_run: bool = Field(default=False, description="Report what would change.")
    notify: bool = Field(default=True, description=(
        "Email affected users when the action completes."))

def apply_bulk_action(
    action: BulkAction, target_org_id: str, options: BulkActionOptions | None = None,
) -> BulkResult: ...
```
