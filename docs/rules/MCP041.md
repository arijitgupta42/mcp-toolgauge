# MCP041 -- read-only tool without readOnlyHint

**Severity:** warning &nbsp;&nbsp; **Rule name:** `read-only-tool-without-hint`

A tool that looks read-only declares no readOnlyHint.

## Why it matters

This is the annotation that *earns* you calls rather than costing them. Clients use
`readOnlyHint` to run safe tools without interrupting the user; an unmarked read gets
the same confirmation prompt as a delete, and every prompt is a chance for the user
to decline or lose the thread.

On a server where most tools are reads, this one annotation is the difference between
an agent that can look things up fluently and one that stops to ask every time.

## Triggers when

`readOnlyHint` is unset and the tool presents itself as a read: the name opens with
`get`, `list`, `search`, `find`, `read`, `fetch`, `export` and similar, or the
description opens with "Returns", "Retrieve", "Lists", and so on.

## Before

```python
@mcp.tool()
def search_users(query: str) -> list[User]:
    """Find people in the staff directory."""
```

## After

```python
READ_ONLY = ToolAnnotations(
    readOnlyHint=True, destructiveHint=False, idempotentHint=True
)

@mcp.tool(annotations=READ_ONLY)
def search_users(query: str) -> list[User]:
    """Find people in the staff directory."""
```
